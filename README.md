# HY-Intelligence organization defaults

This repository contains shared GitHub community-health files and contribution defaults for the HY-Intelligence organization.

Repository-specific guidance takes precedence when a repository provides its own templates or policies.

## Contents

- `profile/README.md` — public organization profile
- `CONTRIBUTING.md` — shared contribution workflow
- `SECURITY.md` — security reporting guidance
- `PULL_REQUEST_TEMPLATE.md` — default pull request checklist
- `.github/ISSUE_TEMPLATE/` — default issue forms

Do not place credentials, customer data, private architecture details, or other confidential material in this public repository.
