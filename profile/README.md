# HY-Intelligence

HY-Intelligence develops software and research foundations for geospatial imagery, raster processing, visualization, and analysis.

Our engineering work emphasizes clear contract boundaries between data semantics, processing/rendering, user interaction, product applications, and experimental research. We prefer reusable core capabilities, explicit validation, reproducible experiments, and evidence-based design decisions.

## Engineering principles

- Keep domain meaning independent from UI and platform details.
- Separate reusable runtime/SDK responsibilities from product-specific behavior.
- Treat experiments and PoCs as reproducible evidence rather than hidden product logic.
- Prefer explicit contracts, measurable performance, and graceful failure over implicit assumptions.
- Keep sensitive data, credentials, customer material, and private architecture details out of public repositories.

Public repositories, when available, contain only material intended for public distribution.
